Sensors · Q1 · First Author

A Comprehensive Review of Sequence and Generative Models in Motor Imagery Classification for Brain–Computer Interfaces

Muhammad Ahmed Abbasi, Hafza Faiza Abbasi, Muhammad Arsalan, Danish Khan, A. Annuk, Xiaojun Yu

Abstract

Motor imagery classification is central to brain–computer interfaces, connecting neural intent with external devices. This review examines sequence-oriented, attention-based, hybrid and generative architectures—including RNNs, LSTMs, VAEs, GANs and transformers—across public MI datasets. It compares their strengths, limitations and robustness while addressing inter-subject variation, low signal-to-noise ratio, real-time processing, generalization and computational load.

Motor Imagery Classification Using Parallel Convolution Transformer Based Feature Extraction and RSA Optimized Ridge ELM Classifier

Hafza Faiza Abbasi*, Muhammad Ahmed Abbasi*, Muhammad Zulkifal Aziz, Binwen Huang, Zeming Fan, Xiaohua Wu, Xiaojun Yu

Abstract

This work introduces CTER, an end-to-end EEG decoding framework combining a parallel transformer and CNN to capture global dependencies and local temporal features. The fused representation is classified using ridge-regression ELM optimized by the reptile search algorithm. Evaluation across four public BCI datasets demonstrates strong classification performance.

TriNet: A Hybrid Feature Integration Approach for Motor Imagery Classification in Brain–Computer Interfaces

Hafza Faiza Abbasi*, Muhammad Ahmed Abbasi*, Shen Jianbo, Xiang Liping, Xiaojun Yu

Abstract

TriNet unifies spectral, spatial and temporal EEG representations. FFT extracts spectral information, a spatial transformer captures spatial relationships, and an encoder–decoder branch learns temporal features. Their fused representation is classified with an extreme learning machine and demonstrates strong subject-specific and subject-independent performance.

A Novel Precisely Designed Compact Convolutional EEG Classifier for Motor Imagery Classification

Muhammad Ahmed Abbasi, Hafza Faiza Abbasi, Muhammad Zulkifal Aziz, Waseem Haider, Zeming Fan, Xiaojun Yu

Abstract

CCEC is a compact convolutional EEG classifier designed for precise and efficient motor-imagery recognition. Multiscale PCA denoises the signal before a two-step preprocessing method creates tempo-spatial matrices. Benchmark tests show robust subject-specific performance, practical cross-subject adaptation and reliable behavior under noise.

Muhammad Ahmed Abbasi, Hafza Faiza Abbasi, Muhammad Zulkifal Aziz, Junzhe Wang, Xiaohua Wu, Xiaojun Yu

Abstract

The framework combines multiscale PCA denoising with power spectral density, continuous wavelet transform and Hilbert-transform features. These complementary representations are fused and classified using AlexNet, achieving approximately 99.2% accuracy on a public dataset.
